Это программа для анализа данных датчика гироскопа-акселерометра.

Название файла данных "MPU_raw_data_.txt".
Константы:

Для преобразования сырых (16-битных) данных с датчика MPU6500 в физические величины (градусы в секунду для гироскопа и g для акселерометра) нужно разделить их на коэффициент чувствительности (Scale Factor), который зависит от выбранного диапазона измерения в регистрах конфигурации.

Перевод в физические единицы

Акселерометр (в единицы g):
Разделите сырое число на коэффициент из таблицы диапазона:

Диапазон ±2g: 		разделить на 16384
Диапазон ±4g: 		разделить на 8192
Диапазон ±8g: 		разделить на 4096
Диапазон ±16g: 		разделить на 2048

Гироскоп (в градусы в секунду, °/с):
Разделите сырое число на коэффициент из таблицы диапазона:

Диапазон ±250°/с: 	разделить на 131.0
Диапазон ±500°/с: 	разделить на 65.5
Диапазон ±1000°/с: 	разделить на 32.8
Диапазон ±2000°/с: 	разделить на 16.4
